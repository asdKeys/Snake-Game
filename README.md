# Snake Game

## About

Play snake in python.

## How to Run

Looking at the screenshots isn't nearly as cool as trying it out yourself so just go to https://www.onlinegdb.com/online_python_compiler#, then scroll up and double click the file called "main.py". Then, copy and paste that code into the python compiler. To run the code properly, you must click the drop-down arrow next to the run button and then press "Run with display screen(beta)" as demonstrated in the screenshot below. If the display screen takes more than 20 seconds to connect or something goes wrong, just refresh and try again.
